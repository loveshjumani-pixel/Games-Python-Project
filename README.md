## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

2. Open the game folder you want to play.

3. Install the required dependencies:

```bash
pip install pygame
```

4. Run the Python file:

```bash
python main.py
```
